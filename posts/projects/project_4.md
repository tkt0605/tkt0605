AIを「しゃべる主役」ではなく、理解する・つなぐ・整理するための静かな知性として置いたネットワーク。滞在時間やフォロワー数ではなく、考えの深さと接続の密度を高めることを目指している。

- 考えを整理する **CLARIFY**、関連する考えを埋め込みベクトルで結ぶ **CONNECT**、会話から気づきを抽出する **DISTILL** の3つの役割をAIが担う
- 技術スタック: Vue 3 / Vite / TypeScript / Supabase（pgvector）/ Tailwind CSS
